# 主线 / 支线 · 轻量任务看板

一个无需构建工具、无需后端的中文单页任务看板。打开 `index.html` 即可使用。

![界面预览](page-screenshot.png)

## 功能

- 主线与支线任务，支持截止日期、完成状态和子项目说明
- 六种视觉主题，可拖动、调整大小、锁定或收起窗口
- 时钟时区与字体大小设置
- 可拖动的灵感草稿本，自动保存在本地，支持粘贴图片
- 任务、设置与草稿只存储在当前浏览器的 `localStorage` 中，不会上传到服务器

## 使用

下载或克隆仓库后，直接用现代浏览器打开 `index.html`。主题图片和校徽素材需与页面保持现有目录结构。

## 隐私

本项目没有服务器端组件，也不主动发送任务或草稿内容。清理浏览器站点数据会同时清除本地保存的数据。
